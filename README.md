# نظام إدارة حلقات مسجد طه

مشروع Django لإدارة الحلقات القرآنية والدورات الإضافية والأساتذة، بحساب إداري واحد فقط.

## المميزات
- تسجيل دخول حصري لحساب إداري واحد (بدون تسجيل عام)
- **الحلقات**: عرض كل حلقة ككرت يتلوّن تلقائياً (🔴 أحمر = لم يكتمل تسجيل الحضور اليوم، 🟢 أخضر = اكتمل)، مع بحث فوري عن أي طالب بالاسم
- **تسجيل حضور تلقائي**: أربع حالات — حاضر / تأخر / إذن / غائب — تُحفظ فوراً بالضغط بدون زر حفظ، لكل طالب وللأستاذ المسؤول عن الحلقة
- **الدورات والدروس الإضافية**: دروس لفئة محددة من الطلاب (من أي حلقة)، بحضور مستقل تماماً عن الحلقة الأساسية، بنفس آلية الحلقة كاملة (تلوين، تنقّل، تصدير...)
- **الأساتذة**: صفحة موحّدة تعرض كل الأساتذة (المرتبطين بحلقة/دورة وغير المرتبطين)، مع إمكانية تسجيل "تفقد عام" لمن لم يُؤخذ له حضور اليوم
- **الغائبون**: صفحة تعرض الغائبين والمتأخرين والمسجَّلين إذن ليوم محدد، مع إمكانية تعديل حالة أي طالب مباشرة من نفس الصفحة، وعدد أيام غيابه آخر أسبوع/شهر
- **جرد تفصيلي**: صفحة ملف لكل طالب وكل أستاذ تعرض بياناته وسجل حضوره الكامل (مع صفحات Pagination)
- **تصدير CSV** يومي لحضور أي حلقة أو دورة أو لكل شيء دفعة واحدة
- **تكامل تلغرام**: إرسال نسخة احتياطية يومية لقاعدة البيانات، وسجل فوري لأي عملية حذف/تعديل من لوحة التحكم
- **الحضور السابق مباشرة**: بجانب كل طالب في صفحات الحلقة/الدورة/الغائبين شريط ملوّن لآخر 10 جلسات مع نسبة حضوره، بدون ضغط أي زر
- **روابط الأسماء**: الضغط على اسم أي طالب (في الحلقات، الدورات، الغائبين، الإحصائيات، السبر، البحث، لوحة التحكم) يفتح صفحة حضوره
- **الإحصائيات**: نسب مئوية بدل الأعداد، فترة «من تاريخ … إلى تاريخ» مع اختصارات سريعة، فرز الطلاب حسب نسبة الغياب/الحضور/الحلقة/العمر/الاسم، فلترة حسب العمر، مخططات SVG تعمل دون مكتبات خارجية، وتقرير PDF بنفس الفلاتر
- **تاريخ الميلاد** للطالب (يُحسب منه العمر تلقائياً)
- **السبر**: خانة لتفاصيل السبر والملاحظات مع إمكانية تعديلها
- **بحث محلي**: أسماء الطلاب تُخزَّن في المتصفح (localStorage) فيتم البحث فوراً دون طلبات للسيرفر، وتُحدَّث تلقائياً عند أي تغيير
- **استيراد Excel**: من ملف صادر مسبقاً عن النظام، بوضع «دمج» (إضافة الجديد فقط) أو «استبدال كامل»، مع تنزيل نسخة Excel مباشرة من صفحة المطور
- **حساب مشاهد**: يُنشأ من لوحة التحكم، ويرى الإحصائيات والسبر، ويستطيع إضافة السبر وتعديله
- **الصفحة الرئيسية**: متابعة اكتمال تسجيل الحضور اليومي لكل الحلقات والأساتذة + ملخص اليوم
- **قائمة «خيارات»** جانبية للهاتف، وتبويبات فرعية في لوحة التحكم وصفحة المطور، وصفحة «كيفية الاستخدام»
- **حضور آخر 4 أسابيع** بجانب كل طالب، كل أسبوع في إطار
- **الإحصائيات**: الفترة الافتراضية من أول تاريخ مسجّل حتى اليوم، تفصيل شهري + المتوسط والمجمل، إحصائيات السبر، فلترة وتقسيم صفحات، وخط «دبي» في PDF
- **ترحيل 0006**: يوحّد التواريخ المخزّنة بصيغة غير صحيحة في SQLite (مثل 2026-8-9) ليصبح الترتيب الزمني والفلترة صحيحين
- تصميم متجاوب بالكامل (Mobile-first)، خط Dubai مضمّن فعلياً، الألوان مستوحاة من شعار المسجد

## التشغيل محلياً

```bash
# 1) أنشئ بيئة افتراضية (اختياري لكن يُنصح به)
python -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate

# 2) ثبّت المتطلبات
pip install -r requirements.txt

# 3) نفّذ الترحيلات (Migrations) - إلزامي هذه المرة (نماذج جديدة: Course, TeacherDailyAttendance...)
python manage.py makemigrations
python manage.py migrate

# 4) أنشئ الحساب الإداري الوحيد
python manage.py createsuperuser

# 5) شغّل الخادم
python manage.py runserver
```

ثم افتح المتصفح على: `http://127.0.0.1:8000/`

للوصول من جوالك على نفس الشبكة المحلية:
```bash
python manage.py runserver 0.0.0.0:8000
```
ثم من الجوال افتح `http://<عنوان-IP-الخاص-بجهازك>:8000/`

## إعداد بوت التلغرام

⚠️ **مهم جداً**: التوكن الذي أرسلته مكتوب داخل `masjid_taha/telegram_secrets.py` وهو ملف **مستثنى من git تلقائياً** (لن يُرفع أبداً إن استخدمت git). لا تشارك محتوى هذا الملف مع أحد. بما أن التوكن ظهر في محادثتنا نصياً، يُفضّل إعادة توليده من BotFather (أرسل له `/revoke`) إن كان هناك احتمال أن يطّلع عليه أحد غيرك.

**الخطوة الناقصة: تحديد وجهة الرسائل (`chat_id`)**
1. أرسل أي رسالة لبوتك على تلغرام (أو أضفه لمجموعة وأرسل فيها رسالة)
2. افتح في المتصفح: `https://api.telegram.org/bot<التوكن>/getUpdates`
3. ابحث عن `"chat":{"id": ...}` وانسخ الرقم
4. افتح `masjid_taha/telegram_secrets.py` وضع الرقم في `TELEGRAM_CHAT_ID`

**تجربة الإرسال يدوياً:**
```bash
python manage.py send_telegram_backup
```

**جدولة الإرسال اليومي التلقائي (لينكس - crontab):**
```bash
crontab -e
```
أضف سطراً (مثال: كل يوم الساعة 11 مساءً):
```
0 23 * * * cd /path/to/masjid_taha && /path/to/venv/bin/python manage.py send_telegram_backup >> /path/to/masjid_taha/telegram_backup.log 2>&1
```

**على ويندوز:** استخدم "جدولة المهام" (Task Scheduler) لتشغيل نفس الأمر يومياً:
```
"C:\path\to\venv\Scripts\python.exe" manage.py send_telegram_backup
```
مع تحديد "Start in" إلى مجلد المشروع.

**سجل عمليات لوحة التحكم**: أي حذف أو تعديل (حلقة/طالب/دورة/أستاذ) يُرسل تلقائياً كرسالة نصية لنفس المحادثة. لتعطيل هذا دون التأثير على النسخة الاحتياطية، غيّر `TELEGRAM_LOG_ADMIN_ACTIONS = False` في `settings.py`.

## خط Dubai
تم تضمين خط **Dubai** الفعلي داخل المشروع (وزنين: Regular و Medium) في:
`halaqat/static/halaqat/fonts/Dubai-Regular.ttf` و `Dubai-Medium.ttf`

سيظهر بنفس الشكل لكل الزوار بدون الحاجة لتثبيته على أجهزتهم. نظراً لعدم توفر ملف Bold مستقل، تم استخدام وزن Medium أيضاً للنصوص الغامقة (font-weight: 700) لتفادي التثقيل الصناعي القبيح من المتصفح.

## ملاحظات أمنية قبل النشر الفعلي على الإنترنت
- غيّر `SECRET_KEY` في `settings.py`
- اجعل `DEBUG = False`
- حدد `ALLOWED_HOSTS` بدقة (اسم النطاق فقط)
- استخدم قاعدة بيانات إنتاجية (PostgreSQL مثلاً) بدلاً من SQLite إن كان الاستخدام كبيراً
- فعّل HTTPS
- لا ترفع `telegram_secrets.py` لأي مكان عام
